# URL Existence Checker
A single-page TypeScript application built with Vanilla TS and Vite that validates URL formatting and queries a mocked asynchronous backend to check resource existence.

## Setup & Running
- Install dependencies: `npm install`
- Start development server: `npm run dev`

## Time Spent
Total Execution Time: **~2 hours** (including setup, implementation, styling, testing, also figuring out some in unfamiliariar things with Typescript).
